&serverTimezone=UTC         ← Define timezone
&allowPublicKeyRetrieval=true ← Permite autenticação

Dialeto Hibernate:
──────────────────

❌ ERROS COMUNS
═══════════════════════════════════════════════════════════════════════════════

ERRO 1: Aspas duplas na URL
─────────────────────────────
❌ ERRADO:
spring.datasource.url="jdbc:mariadb://localhost:3306/catequese"

✅ CORRETO:
spring.datasource.url=jdbc:mariadb://localhost:3306/catequese

Motivo: Properties não usa aspas para strings, elas são interpretadas literalmente


ERRO 2: Driver não definido
────────────────────────────
❌ ERRADO:
spring.datasource.url=jdbc:mariadb://localhost:3306/catequese
(sem driver-class-name)

✅ CORRETO:
spring.datasource.url=jdbc:mariadb://localhost:3306/catequese
spring.datasource.driver-class-name=org.mariadb.jdbc.Driver

Motivo: Spring precisa saber qual driver usar


ERRO 3: Dialeto errado
──────────────────────
❌ ERRADO (para MariaDB):
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect

✅ CORRETO (para MariaDB):
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MariaDBDialect

Motivo: MariaDB tem seu próprio dialeto otimizado


ERRO 4: Variáveis de ambiente em development
──────────────────────────────────────────────
❌ ERRADO:
spring.datasource.url=${SPRING_DATASOURCE_URL}
(sem variável definida)

✅ CORRETO (se usar variáveis):
1. Definir variável de ambiente
2. Ou usar valor literal para desenvolvimento

Motivo: ${...} procura por variáveis de ambiente
