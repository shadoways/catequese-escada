jdbc:mariadb://
  → Protocolo de conexão (especifica que é MariaDB)
localhost:3306
  → Host e porta do servidor MariaDB
  → localhost = sua máquina local
  → 3306 = porta padrão do MariaDB
catequese
  → Nome do banco de dados
?useSSL=false
  → Desabilita SSL para desenvolvimento
  → Use "true" em produção
&serverTimezone=UTC
  → Define o timezone para UTC
  → Evita problemas com datas
&allowPublicKeyRetrieval=true
  → Permite autenticação segura

⚠️ ERROS COMUNS E SOLUÇÕES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ERRO 1: "Connection refused"
──────────────────────────
  Causa: MariaDB não está rodando
  Solução: sudo systemctl start mariadb
           ou
           sudo service mariadb start
ERRO 2: "Access denied for user 'root'@'localhost'"
──────────────────────────────────────────────────
  Causa: Senha incorreta
  Solução: Verificar a senha em application.properties
           Resetar senha do root se necessário
ERRO 3: "Unknown database 'catequese'"
──────────────────────────────────────
  Causa: Banco não existe
  Solução: CREATE DATABASE catequese;
ERRO 4: "No suitable driver found"
──────────────────────────────────
  Causa: Driver não instalado
  Solução: ./gradlew clean build --refresh-dependencies
